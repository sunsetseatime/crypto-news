# Demo Guide

This is a daily crypto scan dashboard. The data comes from the latest reports.

## Quick walk-through
1) Check the run time at the top of the dashboard.
2) Review Alerts and Summary to see what changed today.
3) Click a coin row to open details and read the reasons and risks.
4) Open the Paper Trading card and click the report link.
5) Use Chat only for coins shown on the dashboard. It answers from the reports (and may pull a short project description from CoinGecko).
